Benchmark dataset

QAOA vs classical solvers, measured on real silicon.

Numbers come from the project's own benchmark harness (qaoa-portfolio benchmark) on seeded, paired instances, so each host and simulator backend solves the same problems; portfolios above 20 assets were measured with campaign scripts that rebuild the same instances outside the harness. Quality is the approximation ratio against the brute-force optimum: 1.0 means the optimum was found.
